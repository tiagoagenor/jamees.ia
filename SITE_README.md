# JAMEES - Sistema de Gestão Empresarial

## 🚀 Site Institucional Criado

Criamos um site institucional completo para o JAMEES baseado no design do [Bling](https://www.bling.com.br/), incluindo:

### 📄 Páginas Criadas

#### 1. **Landing Page** (`/`)
- **URL**: `http://localhost:8000/`
- **Arquivo**: `resources/views/landing.blade.php`
- **Controller**: `app/Http/Controllers/LandingController.php`

#### 2. **Página de Demonstração** (`/demo`)
- **URL**: `http://localhost:8000/demo`
- **Arquivo**: `resources/views/demo.blade.php`

### 🎨 Design e Funcionalidades

#### **Landing Page Principal**
- ✅ **Header responsivo** com navegação e CTA
- ✅ **Seção Hero** com call-to-action principal
- ✅ **Seção de Recursos** com 6 cards principais:
  - Gestão Financeira
  - Controle de Estoque
  - Gestão de Vendas
  - Contas Bancárias
  - Formas de Pagamento
  - Relatórios Inteligentes
- ✅ **Seção de Preços** com 3 planos:
  - Plano Base (R$ 39/mês)
  - Plano Premium (R$ 79/mês) - Mais Popular
  - Plano Master (R$ 149/mês)
- ✅ **Seção de Depoimentos** com testimonials
- ✅ **CTA Final** com gradiente
- ✅ **Footer completo** com links e informações

#### **Página de Demonstração**
- ✅ **Demonstrações visuais** das principais funcionalidades
- ✅ **Cards interativos** com screenshots simulados
- ✅ **Seções organizadas** por módulo do sistema
- ✅ **CTA para teste grátis**

### 🛠️ Tecnologias Utilizadas

- **Frontend**: HTML5, Tailwind CSS, Font Awesome
- **Backend**: Laravel (PHP)
- **Estilos**: CSS customizado com animações
- **Responsividade**: Design mobile-first
- **Interatividade**: JavaScript vanilla
